# ADR-0010: 本地分流规则设计

**Status:** Accepted
**Date:** 2026-07-14

**Context:**

远程规则集覆盖了绝大多数服务的分流需求，但某些流量需要本地规则优先处理：金融类服务必须直连以确保稳定和安全，P2P/版权内容需要拦截，特定 IP 段需要绕过代理。

**Decision:**

在 `[filter_local]` 中定义三层本地规则，优先级高于远程规则：

| 类别 | 规则 | 策略 | 理由 |
|------|------|------|------|
| 版权保护 | `hub5*.v6.shub.sandai.net` | REJECT | 屏蔽迅雷 P2P 版权检测 |
| 金融服务 | 18+ 家银行域名后缀（`icbc.com.cn`、`ccb.com` 等） | DIRECT | 金融交易必须直连，避免代理引入的安全风险和不稳定 |
| IP 直连 | `188.180.0.0/16` | DIRECT | 该网段强制直连（可能是运营商内网或不需要代理的 CDN） |

兜底策略 `FINAL, 漏网之鱼` 使未匹配的流量进入 漏网之鱼 策略组。

**Consequences:**

- 金融类域名本地直连：避免代理节点故障导致银行/支付不可用，也规避了数据经境外节点的合规风险
- 迅雷域名 REJECT：阻止 BitTorrent 相关流量，避免 P2P 滥用带宽
- 本地规则数量极少（~20 条），维护成本低，与远程规则集互补
- 本地规则优先级高于远程，确保了关键流量的确定性路由
